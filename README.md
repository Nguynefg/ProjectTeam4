# Project mẫu: Website giới thiệu nhóm

Website HTML, CSS, JavaScript đơn giản để thực hành Git và GitHub. Không cần cài thư viện: mở `index.html` bằng trình duyệt, rồi nhấn **Chào cả nhóm**.

## Các file

| File | Chức năng |
| --- | --- |
| index.html | Nội dung và danh sách thành viên |
| style.css | Giao diện |
| script.js | Nút chào cả nhóm |
| HUONG-DAN-GITHUB.md | Các bước tạo repository và cộng tác |
| MINH-CHUNG-NHOM.md | Mẫu thu thập bằng chứng đóng góp thật |

## Bài thực hành cho 3 người (có thể thêm người)

- A: thay tên mẫu trong HTML bằng tên thật, thêm mô tả nhóm.
- B: đổi màu chủ đạo, cải thiện giao diện trên điện thoại.
- C: sửa lời chào, kiểm tra nút và ghi kết quả vào pull request.

Mỗi người sử dụng tài khoản riêng, một nhánh riêng, tạo ít nhất một commit và một pull request. Một người khác review trước khi merge. Xem hướng dẫn chi tiết trong `HUONG-DAN-GITHUB.md`.

Đây là project minh họa được chuẩn bị cục bộ. Chưa có repository GitHub trực tuyến hay bằng chứng nhóm thực sự đóng góp.
