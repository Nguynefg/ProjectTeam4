# ProjectTeam4 — Website giới thiệu nhóm 6 thành viên

Website sử dụng HTML, CSS và JavaScript để thực hành Git và GitHub. Nhóm cùng sửa nội dung, quản lý lịch sử thay đổi và review qua pull request.

- Repository: https://github.com/Nguynefg/ProjectTeam4
- Địa chỉ GitHub Pages: https://nguynefg.github.io/ProjectTeam4/

## Cách chạy

Tải hoặc clone project, mở `index.html` bằng trình duyệt rồi nhấn **Chào cả nhóm nha** để thử chức năng JavaScript. Không cần cài thư viện.

```bash
git clone https://github.com/Nguynefg/ProjectTeam4.git
cd ProjectTeam4
```

## Các file

| File | Chức năng |
| --- | --- |
| index.html | Nội dung và danh sách 6 thành viên |
| style.css | Màu sắc, bố cục và giao diện |
| script.js | Chức năng nút chào |
| HuongDanKetNoiGitHub.md | Hướng dẫn kết nối, sửa file và cộng tác |
| MinhChungNhom.md | Tổng hợp đóng góp, commit, pull request và review |

## Quy trình làm việc chung

1. Mỗi người sử dụng tài khoản GitHub riêng và chấp nhận lời mời Collaborator.
2. Clone project về máy, cập nhật `main` trước khi bắt đầu công việc.
3. Tạo nhánh riêng, sửa và lưu file.
4. Commit và push thay đổi lên GitHub.
5. Tạo pull request vào `main`.
6. Thành viên khác review trước khi merge.
7. Sau khi merge, cả nhóm lấy phiên bản mới nhất về máy.

```bash
git switch main
git pull --ff-only origin main
```

Lưu và commit công việc đang làm trước khi chuyển nhánh. Hướng dẫn chi tiết nằm trong [HuongDanKetNoiGitHub.md](HuongDanKetNoiGitHub.md).

## Minh chứng đóng góp

Ghi link commit, pull request, review và ảnh PR đã merge của từng người vào [MinhChungNhom.md](MinhChungNhom.md).

Danh sách tên trên website là phần giới thiệu. Đóng góp thực tế của 6 thành viên được xác nhận bằng lịch sử commit, pull request và review.
